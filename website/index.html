Engineered for Safety & Speed

Built Different from the Ground Up

Designed with strict security boundaries, high frame-rate responsiveness, and zero bloated domain coupling.

OS KERNEL
🛡️

Policy + Kernel Containment

Two separate safety layers: octane-permission checks policy before running, while octane-sandbox enforces Seatbelt / Landlock / AppContainer rules at the OS kernel level.

  • Read-only enforcement on .git/ and .octane/
  • No parameter interpolation — zero injection risks
  • Strict Precedence: Deny > Ask > Allow
TUI STREAMING
⚡

Synchronized Streaming TUI

Full-screen Ratatui output wrapped in synchronized-output escapes (CSI ?2026h/l). Zero flickering, 0-byte idle repaints, and pure state-in/lines-out rendering.

  • Smart follow-tail auto-scrolling
  • Subsequence path/command completion (e.g. @octcli)
  • Width-safe ASCII & Unicode fallback styling
GATEWAY
🌐

Universal Provider Router

Per-model api and baseUrl configuration. Bridge OpenAI, Anthropic, Google Gemini, Vertex, and SigV4 gateways seamlessly from one profile.

  • Env variable substitution with clear missing-var error traces
  • Auth support: API keys, Google Vertex, AWS SigV4, TokenFile
  • Full support for OpenRouter & custom enterprise proxies
MCP & TOOLS
🧰

7 Built-in Safe Tools + MCP

Ships with read, write, edit, bash, glob, grep, and list. Fully protocol-compliant with Model Context Protocol (MCP) over JSON-RPC.

  • Glob search sorted by mtime for instant relevance
  • Deterministic BTreeMap schema serialization
  • Loop detection hashing (tool, input, output)
CONTEXT
🧠

Context & Memory Layering

Hierarchical OCTANE.md & AGENTS.md memory loading with @import support, automatic token budget pruning, and context compaction thresholds.

  • Progressive skill discovery
  • Append-only prompt history (never mutates past turns)
  • Safety rail step caps and loop detection
ARCHITECTURE
⚙️

Pure Rust 2024 Architecture

Strictly acyclic crate hierarchy. Zero domain logic in octane-core — every collaborator is a trait, making the agent loop fully mockable and testable without a network.

  • Nix Flake integrated toolchain (no rustup needed)
  • Forbid unsafe code across workspace
  • 580+ unit, integration, and security assertion tests

Workspace Layout

13 Specialized Rust Crates

Strict one-way dependency graph ensuring clean separation of concerns.

OS Kernel

octane-sandbox

OS enforcement via Seatbelt / Landlock / AppContainer boundaries.

Policy Engine

octane-permission

Action policy decision engine: Allow, Ask, or Deny rules.

Tool Execution

octane-tools

Built-in tools: read, write, edit, bash, glob, grep, list.

LLM Router

octane-provider

LanguageModel trait, normalized stream events, and provider transforms.

Shared Protocol

octane-protocol

Defines Thread, Turn, Item, Message, Part, and Event wire formats.

ReAct Loop

octane-core

Agent coordination, ReAct loop, stop conditions, and prompt assembly.

Crate Architecture

octane-sandbox

Enforces real OS containment utilizing native kernel features (macOS Seatbelt, Linux Landlock, Windows AppContainer). Ensures processes spawning tool tasks cannot touch files outside declared workspace roots or write to .git/ hooks.

Ownership Boundary
OWNS: Seatbelt / Landlock / AppContainer containment
DOES NOT OWN: User consent decisions (handled by octane-permission)
Flexible Gateway Routing

Drop-in JSON Provider Configuration

Supports OpenRouter, Anthropic, OpenAI, Google Gemini, and custom corporate LLM proxies.

{
  "api": "openai-completion",
  "baseUrl": "https://openrouter.ai/api/v1",
  "auth": { "type": "apiKey", "value": "${OPENROUTER_API_KEY}" },
  "defaults": { "primary": "claude-3.7", "faster": "flash" },
  "models": {
    "claude-3.7": { "id": "anthropic/claude-3.7-sonnet" },
    "flash":      { "id": "google/gemini-2.0-flash-001" }
  }
}

Get Started

Up and Running in Seconds

Zero external runtime dependencies. Powered by Nix Flake & Cargo.

01

Install octane CLI

Install directly using Cargo from source repository or crates.io.

cargo install octane-cli
02

Verify Setup

Run diagnostic checks and verify tool execution without spending tokens.

octane doctor
03

Launch Interactive TUI

Start an interactive session with full OS containment and live streaming.

octane
01

Clone & Direnv

The Nix flake owns the Rust 2024 toolchain — no rustup management needed.

git clone https://github.com/raymond/octane-agent cd octane-agent direnv allow
02

Run via Flake

Run octane agent immediately without installing local system packages.

nix run github:raymond/octane-agent -- doctor
03

Launch Session

Enter a sandboxed shell environment with all dependencies auto-loaded.

nix develop
