ENGINEERED FOR SPEED & SECURITY

Built from the ground up in Rust with zero domain logic coupling.

01 /// OS CONTAINMENT

Kernel Sandboxing

Enforces process boundaries at the OS level using Seatbelt (macOS) and Landlock (Linux). Read-only protections on .git/ and .octane/.

02 /// TUI ENGINE

Synchronized Streaming TUI

Ratatui full-screen interface using synchronized output mode (CSI ?2026h/l) for 100% flicker-free rendering and zero-byte idle repaints.

03 /// GATEWAY ROUTING

Multi-Provider LLM Gateway

Bridge OpenAI, Anthropic, Google Gemini, OpenRouter, Vertex, and AWS SigV4 gateways with granular per-model route configuration.

04 /// TOOLING & MCP

8 Safe Tools + MCP

Built-in read, write, edit, bash, code search (grep, glob, list), and subagents (task), plus standard MCP support.
