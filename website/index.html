03

BUILD ORDER

From agent
to platform.

The current runtime stays at the center. Each stage earns the next one.

NOW

Finish the core

  • Complete terminal UI polish
  • Bring skills into every run
  • Finish Windows support
  • Stabilize the app foundation
NEXT

Workflow runtime

  • Saved, versioned workflows
  • Branches and parallel work
  • Approvals, retries, and fallbacks
  • Checkpoint and resume
THEN

Desktop Studio

  • Visual builder and inspector
  • Live run view
  • Approval inbox
  • Replay and workflow history
LATER

Model Studio

  • Quality and cost evaluation
  • Smarter model routing
  • Private and local deployment
  • Specialized model support

Custom models come after workflows produce trustworthy runs and evaluations—not before.
