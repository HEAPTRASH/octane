BUILT DIFFERENT FROM GROUND UP

Strict security boundaries, high frame-rate responsiveness, and zero domain coupling.

01 /// OS KERNEL

POLICY + KERNEL CONTAINMENT

Two separate safety layers: octane-permission checks policy before running, while octane-sandbox enforces Seatbelt / Landlock / AppContainer rules at the OS kernel level.

  • Read-only enforcement on .git/ & .octane/
  • Zero parameter interpolation — zero shell injection risk
  • Strict Precedence: Deny > Ask > Allow
02 /// TUI ENGINE

SYNCHRONIZED STREAMING TUI

Full-screen Ratatui output wrapped in synchronized-output escapes (CSI ?2026h/l). Zero flickering, 0-byte idle repaints, and pure state-in/lines-out rendering.

  • Smart follow-tail auto-scrolling
  • Subsequence path/command completion
  • Width-safe ASCII & Unicode fallback styling
03 /// GATEWAY

UNIVERSAL PROVIDER ROUTER

Per-model api and baseUrl configuration. Bridge OpenAI, Anthropic, Google Gemini, Vertex, and SigV4 gateways seamlessly from one profile.

  • Env variable substitution with trace logs
  • Auth: API keys, Google Vertex, AWS SigV4, TokenFile
  • Full support for OpenRouter & enterprise proxies
04 /// MCP & TOOLS

8 BUILT-IN SAFE TOOLS + MCP

Ships with read, write, edit, bash, glob, grep, list, and subagent delegation via task. Fully protocol-compliant with Model Context Protocol (MCP) over JSON-RPC.

  • Glob search sorted by mtime for instant relevance
  • Deterministic BTreeMap schema serialization
  • Loop detection hashing (tool, input, output)
05 /// CONTEXT

CONTEXT & MEMORY LAYERING

Hierarchical OCTANE.md & AGENTS.md memory loading with @import support, automatic token budget pruning, and context compaction thresholds.

  • Progressive skill discovery
  • Append-only prompt history (never mutates past turns)
  • Safety rail step caps and loop detection
06 /// ARCHITECTURE

PURE RUST 2024 ARCHITECTURE

Strictly acyclic crate hierarchy. Zero domain logic in octane-core — every collaborator is a trait, making the agent loop fully mockable and testable without a network.

  • Nix Flake integrated toolchain
  • Forbid unsafe code across workspace
  • 683 unit, integration, and security tests
